**俄罗斯钓鱼4（Russian Fishing 4）**

统一拓展管理框架与管理器、拓展模块、单机拓展服务器。

## 使用方法

1. 下载并解压 MF Manager，运行 `RF4-MF-Manager.exe`。
2. 下载并解压 MODServer，在管理器中配置服务端路径。
3. 下载所需 MOD 模块 ZIP，通过管理器导入。
4. 启动单机服务器及游戏，连接 MF 并启用所需模块。

## 说明

- 支持 Windows x64。
- 各拓展模块独立安装、启停及更新。
- 本项目面向单机离线环境。
- MODServer 基于 [RF4 Server Simulator](https://github.com/OpenFisherCommunity/rf4_server_simulator) 拓展开发。

本项目为非官方社区拓展项目。
